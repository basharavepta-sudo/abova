# Инструкция по установке VST эквалайзера для Windows 10

Этот проект представляет собой VST3 плагин эквалайзера, написанный на Rust. Чтобы использовать его в вашей DAW (Digital Audio Workstation) на Windows, вам необходимо скомпилировать его и установить в папку плагинов.

## 1. Подготовка окружения (Prerequisites)

Перед началом убедитесь, что у вас установлены следующие инструменты:

1.  **Rust и Cargo**: Скачайте и запустите установщик `rustup-init.exe` с официального сайта [rust-lang.org](https://www.rust-lang.org/tools/install).
2.  **C++ Build Tools**: Во время установки Rust вам может потребоваться установить "Visual Studio C++ Build Tools". Если они не установлены, скачайте их с сайта Microsoft (Visual Studio Installer -> Desktop development with C++).

## 2. Сборка проекта (Build)

1.  Откройте командную строку (PowerShell или CMD) в папке проекта `my_eq`.
2.  Запустите команду сборки релизной версии:
    ```cmd
    cargo build --release
    ```
3.  Дождитесь окончания сборки. Это может занять несколько минут, так как будут скачаны и скомпилированы зависимости.

## 3. Упаковка и Установка (Installation)

После успешной сборки файл плагина будет находиться по пути:
`target\release\my_eq.dll`

### Стандарт VST3

VST3 плагины на Windows обычно распознаются, если они имеют расширение `.vst3`.

1.  Перейдите в папку `target\release`.
2.  Найдите файл `my_eq.dll`.
3.  Создайте структуру папок для плагина (рекомендуется):
    *   Создайте папку `MyEq.vst3`
    *   Внутри неё создайте папку `Contents`
    *   Внутри `Contents` создайте папку `x86_64-win`
    *   Скопируйте `my_eq.dll` в папку `x86_64-win` и переименуйте его в `MyEq.vst3`.

    *Итоговый путь:* `MyEq.vst3\Contents\x86_64-win\MyEq.vst3`

    *Примечание: Часто достаточно просто переименовать `my_eq.dll` в `MyEq.vst3` и скопировать его, но использование папки является стандартом.*

### Копирование в системную папку

Скопируйте папку `MyEq.vst3` (или файл `MyEq.vst3`) в стандартную директорию VST3 плагинов Windows:

`C:\Program Files\Common Files\VST3`

## 4. Проверка

1.  Запустите вашу DAW (Reaper, Cubase, FL Studio, Ableton и т.д.).
2.  Выполните сканирование плагинов (Scan Plugins).
3.  Найдите "My Equalizer" (или "MyEq") в списке эффектов.

## CLAP формат

Если ваша DAW поддерживает формат CLAP (например, Bitwig, Reaper), вы также можете использовать файл `my_eq.dll` переименовав его в `MyEq.clap` и скопировав в:
`C:\Program Files\Common Files\CLAP`
